# Dead Air Radio — Project Briefing

_Status reconciled against `master` on 2026-09-29._ Source code is authoritative when this note and implementation differ.

## What Is Dead Air Radio?

A React Native / Expo horror game about tuning a radio to mysterious frequencies. Players explore radio bands, receive calls, collect tapes, and manage their sanity in a CRT/analog-horror aesthetic. Hand-authored calls live in `data/calls.js`; procedural and expansion content is separate.

## Revenue Model

- **Base game:** the hand-authored core call experience.
- **Infinite Signal IAP:** store purchase code and the procedural-call entitlement gate are implemented. Owners receive a generated call pool in addition to eligible hand-authored calls.
- **Product IDs:** defined in `lib/constants.ts` and `lib/iap.ts`; the real products, credentials, and pricing must also be configured in App Store Connect and Google Play.

## Current Implementation Status

- The purchase/restore lifecycle is wired through `lib/iap.ts` and the store screen. The entitlement gate checks for a transaction receipt and order ID; app-launch purchase-history revalidation is present. Receipt verification is client-side only in this repository, with no server-side validation service.
- `ProceduralCallGenerator` and its fragment libraries are implemented and tested. `getCallPool()` gates generated calls on Infinite Signal ownership. The generated pool is finite per construction and regenerated by the call manager; “Infinite Signal” describes procedural replayability, not a literally infinite array.
- The tape collection screen has synthesized playback, transport controls, progress, and cleanup on close/navigation.
- Radio-call audio is still a separate gap: the call-manager instance passes `audio: null`, so active calls are not connected to the audio engine for playback.
- Production readiness still depends on external store-console setup, EAS credentials, and real iOS/Android sandbox QA. See `docs/store/release-checklist.md`.

## Project Constraints

- **Do not modify `data/calls.js`** without explicit project approval; its hand-authored calls are the protected narrative source.
- Keep TypeScript strict and run the repository's format, lint, typecheck, circular-dependency, and Jest checks.
- Use Expo-compatible packages and pnpm.
- Verify platform-specific IAP and audio behavior in native sandbox builds before claiming release readiness.
