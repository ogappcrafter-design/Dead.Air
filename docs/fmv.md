# FMV intro & trailer

Dead Air's launch cinematic is a 60-second FMV trailer authored in HyperFrames
(OpenMotion) and rendered to video. The Godot build plays the first 15 seconds
as a launch/attract clip before the title screen, then hands off to the main
menu.

## Pipeline

```
HyperFrames composition  (OpenMotion project ab39a1e2-…)
  index.html + GSAP timeline + imported score WAV
        │  openmotion_export_request (audio: required)
        ▼
Dead Air - FMV Intro & Trailer.mp4   H.264 1080p30 + AAC 48 kHz stereo
        │  scripts/fmv/render_masters.py
        ├──────────────► build/fmv/deadair_fmv_60s_h264.mp4    web/social master
        ├──────────────► build/fmv/deadair_fmv_60s_prores.mov  ProRes 4444 compositing master
        └──────────────► godot/assets/fmv/deadair_intro.ogv    runtime clip (first 15 s)
```

The score is generated by `scripts/fmv/make_audio_bed.py` (original synthesis:
drone, radio static, theme piano — no library samples) and normalised to
−14 LUFS / true peak ≤ −1 dBTP. Its manifest is written next to the WAV.

## Rendering

```bash
# delivery masters + Godot runtime clip from an OpenMotion export
python3 scripts/fmv/render_masters.py \
  --source "/path/to/Dead Air - FMV Intro & Trailer.mp4" \
  --intro-seconds 15
```

The script encodes, then re-probes each artifact with `ffprobe` and measures the
MP4 with `ebur128`; it exits non-zero if resolution, audio presence, or loudness
drift out of tolerance. `build/fmv/render_manifest.json` records codec, size,
duration, and loudness for the files it produced.

Measured on the 2026-11-20 render (version `285f797e-…`):

| artifact      | container | video                    | audio                | loudness              |
| ------------- | --------- | ------------------------ | -------------------- | --------------------- |
| 60 s master   | MP4       | H.264 1920×1080 30 fps   | AAC 48 kHz stereo    | −14.1 LUFS, −1.1 dBTP |
| ProRes master | MOV       | ProRes 4444 yuva444p10le | PCM 24-bit 48 kHz    | source-identical      |
| runtime clip  | Ogg       | Theora 1920×1080 30 fps  | Vorbis 48 kHz stereo | first 15 s            |

## Runtime integration (DEA-199)

`godot/scenes/fmv_intro.tscn` is the launch scene (`run/main_scene` in
`godot/project.godot`). `godot/src/ui/fmv_player.gd`:

- loads `res://assets/fmv/deadair_intro.ogv` into a `VideoStreamPlayer`;
- sets the player's `bus` to `AudioBusManager.BUS_MASTER` so accessibility
  volume and the Master limiter apply to the cinematic;
- skips on any key, joypad button, mouse button, or touch press (mouse motion
  and key releases are ignored), showing a skip hint after 3 s;
- emits `intro_started` / `intro_finished` / `intro_skipped` /
  `intro_unavailable`, then requests `res://scenes/main_menu.tscn` exactly once;
- falls back to the title screen when the clip is missing or undecodable, so a
  stripped build never sits on a black screen.

Godot 4 ships only the Ogg Theora decoder, so the runtime asset is transcoded
rather than the H.264 delivery master. The clip is not an imported resource:
`.ogv` files are read directly by `ResourceFormatLoaderTheora`, and the desktop
export presets use `export_filter="all_resources"`, which includes them.


`tests/test_fmv_player.gd` covers scene wiring, Master-bus routing, skip-on-input,

## CDN hosting

The delivery masters are published to Cloudflare R2 and served from a custom
domain:

```text
https://cdn.timewarper.me/deadair/fmv/60s/deadair_fmv_60s_h264.mp4
```

`motion-assets.json` under `cdn` is the record: `status: published`, the bucket,
the prefix and the URL. Publish and re-verify with:

```bash
set -a; . ./.env; set +a   # R2_ENDPOINT, R2_BUCKET, R2_ACCESS_KEY_ID, R2_SECRET_ACCESS_KEY
CDN_BASE_URL=https://cdn.timewarper.me python3 scripts/fmv/publish_masters.py
CDN_BASE_URL=https://cdn.timewarper.me python3 scripts/fmv/publish_masters.py --check
```

`--check` reads the objects the manifest records as published, then fetches the
recorded URL and compares the served byte count with the bucket object. It sends
`deadair-fmv-publish/1.0`: the zone's bot protection rejects `Python-urllib`
while curl and a Godot user agent pass.

Things that are true of this host and worth knowing before republishing:

- Binding a custom domain goes through `wrangler r2 bucket domain add`; the REST
  `domains/custom` endpoint answers `10040 "The JSON you provided was not well
formed"` to well-formed bodies. Until the domain reports `ssl: active` and
  `ownership: active`, the hostname serves `403 error code: 1014`, and that
  response stays cached at the edge for a while after activation.
- Objects are served `immutable` for a year. A re-render replaces the same object
  key, so a URL handed out earlier keeps resolving to the old bytes in any cache
  that already holds it; publish a new prefix when the bytes must change.
- `--with-compositing` uploads the 3.2 GB ProRes alpha under `deadair/fmv/60s/private/`.
  The `private` prefix is a naming convention, not access control: on a publicly
  readable bucket, anyone with the key can read it. Keep it off the public bucket
  unless a bucket rule actually blocks that prefix.
